## Per-company protocol (budget 90 seconds HARD)
1. Open career URL in a NEW browser tab (tabs action=new with url).
2. Wait ~4-6s for JavaScript rendering (wait tool value=5000).
3. Read/inspect page content (browseros-neo_read or grep for role keywords like
   react/frontend/engineer). If a "View jobs / View openings / See positions"
   button exists, click it ONCE (act kind=click on its ref) and re-read.
4. Extract every matching listing: title, location, application/href URL, job id
   if present, posting age if shown.
5. Append ONE JSONL line PER matching job to %%OUT_FILE%% immediately:

6. Close the tab you opened (tabs action=close with its pageId). Never exceed 2 tabs.
7. Heartbeat line (below) noting "<name>:<n_jobs|skip_reason>".

If a page errors, redirects weirdly, requires login, or shows no readable listings

record only what the rendered page actually shows.
