## HUMANIZED TYPING (mandatory - anti-bot-detection)
CRITICAL: Do NOT use act(kind=fill) or act(kind=press) with multi-character text.
Bulk fill/paste actions are trivially detected by anti-bot systems (Cloudflare,
Datadome, PerimeterX). Type like a real human:

FOR EACH TEXT FIELD:
1. Use act(kind=type, text="<single_char>") for ONE character at a time.
2. Between each character, use wait tool with a Gaussian-distributed delay:
   - Mean: 80ms, StdDev: 30ms (range: 20-250ms)
   - Example: wait 60ms, wait 95ms, wait 42ms, wait 110ms, ...
3. ~2% of the time, type a WRONG adjacent key, wait 120-180ms, then press Backspace.
   This simulates natural typos. Example sequence for "YourFirstName":
   type 'A', wait 72ms, type 'b', wait 88ms, type 'h', wait 55ms,
   type 'i', wait 103ms, type 's' -> WRONG, wait 150ms, press Backspace,
   wait 120ms, type 's', wait 67ms, ...
4. ~8% of the time, insert a longer "thinking" pause of 300-800ms between characters.
5. NEVER type faster than 20ms per character. NEVER type slower than 250ms.

FOR FORM FIELDS:
- After completing a field, pause 200-500ms before tabbing/clicking to the next one.
- When moving between form sections, pause 500-1500ms as if reading the next section.

SCROLLING:

- Wait 1-3 seconds between scroll increments.
- Occasionally scroll UP by 100-200px (simulates re-reading).
